Aide

Comment supprimer ou masquer un message ?

Passez sur le message et cliquez sur ⌄. « Masquer » le cache seulement chez vous. « Supprimer » propose « pour moi » (effacé définitivement de votre appareil) ou « pour tout le monde » (pour vos propres messages).

Qu'est-ce que la vue unique ?

Activez le bouton ① avant d'envoyer : le message (texte, photo ou vocal) ne pourra être ouvert qu'une seule fois, puis il est effacé.

Comment fonctionnent les messages éphémères ?

Dans une discussion, ouvrez le menu ⋮ puis « Messages éphémères ». Les nouveaux messages s'effacent pour tout le monde après le délai choisi. Le délai par défaut se règle ici, dans « Confidentialité ».

Les captures d'écran sont-elles détectées ?

En partie seulement : JokkoChat repère les raccourcis clavier de capture (Impr. écran, Cmd + Maj + 3/4/5, Win + Maj + S) et prévient l'autre personne. Une capture faite sur téléphone ou avec une autre application ne peut pas être détectée.
