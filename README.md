# JokkoChat
## Description

JokkoChat est une application de messagerie instantanée Web permettant aux utilisateurs de communiquer en temps réel, d'échanger des messages privés et de participer à des salons de discussion.
## Fonctionnalités principales

- Inscription et connexion des utilisateurs
- Gestion des contacts
- Conversations privées
- Salons de discussion
- Envoi et réception de messages
- Affichage de l'heure des messages
- Statut en ligne / hors ligne
- Indicateur « En train d'écrire... »
- Partage d'images
- Notifications visuelles ou sonores
## Fonctionnalité supplémentaire

### Résumé automatique des messages

JokkoChat intégrera une fonctionnalité permettant de générer automatiquement un résumé d'un message ou d'un contenu textuel reçu afin d'aider l'utilisateur à comprendre rapidement les informations principales.
